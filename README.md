# Sanya Acupuncture International Patient Service

三亚针灸国际患者服务平台，第一阶段聚焦俄语患者。

## 产品定位

这是一个面向俄罗斯及俄语地区游客的患者服务入口，不是医院官方网站。核心路径：

俄语患者 → 了解针灸与医院 → 提交预约需求 → 确认时间 → 到医院就诊 → 俄语沟通协助 → 后续服务。

## 当前版本

- React + Vite
- Russian / Chinese / English interface
- Responsive mobile-first layout
- GitHub Pages deployment
- Hospital-based positioning without未经授权的官方身份表述
- Pricing explanation focused on transparency rather than promising treatment outcomes

## Important

医疗信息页面不作诊断、疗效保证或固定疗程承诺。医院名称、医生资历、收费、联系方式等正式信息上线前应逐项核验。
